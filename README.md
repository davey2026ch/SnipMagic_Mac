# 截图大师 SnipMagic（macOS 原生）

**截图大师 SnipMagic** 是一款用 Swift 编写的 macOS 原生截图工具：区域截图、滚动长截图、多页签标注编辑、左右对比、缩放、取色、OCR 文字/表格识别，开箱即用。

## 核心特点

**1、支持区域截图、长截图，一张图片占据一个 sheet 页签。**

**2、两图对比：显示页签 A 的图像，再右键点击页签 B，实现 AB 两图左右并列显示，默认开启同步滚动。**

**3、框选图片中某个局部区域后：**

- **（1）马赛克**：点击马赛克按钮，对选中区域打码；
- **（2）移花接木**：使用 `⌘C` `⌘V` 复制、粘贴。可以粘贴到当前图片中、粘贴到其他页签的图片中；
- **（3）粘贴到外部**：把框选区域复制到剪贴板后，粘贴到文档、微信等外部软件；
- **（4）魔法消除**：用「擦除刷」刷出（或框选）要去掉的内容，点按钮交给 AI 重建背景 —— 文字、水印、Logo、杂物都能抹掉，且保留背景纹理。火山 API Key 申请地址（费用超低）：<https://console.volcengine.com/imp/ai-mediakit/settings>。
- **（5）提取矢量图**：框选画面里的主体（图标、人像、商品……），或用「框选」点中一个浮动图层，点按钮交给 AI 抠图，主体被抠成**透明底图层**放回画布 —— 可拖动、可缩放，⌘C 复制到微信 / Keynote / Word 也保留透明。**有浮动图层被激活选中时只处理那一块**，不会带上它下面那一层。与「魔法消除」共用同一把火山 API Key。

**4、左侧工具图标：单击即用、双击锁定。**

- **单击**：图标高亮（蓝底白图标），一眼知道接下来画什么；在画布上画完一个 / 用一次之后**自动退回「框选」**，不用手动切回去；
- **双击**：图标右下角出现一个**小锁**，锁定后可**连续画多个**（交互类似 Office 里锁定的格式批刷），**再单击该图标即解除锁定**并回到「框选」；
- 启动时默认停在「框选」；「框选 / 查看 / 擦除刷」是常驻模式，不会被自动退出。
- 图标常态为**高对比的深色描边**（不跟随系统把那批细线符号压成半透明灰），鼠标悬停时按钮浮出淡色底衬，一眼看得出正指着哪个。
- **「查看」= 定版**：点一下就把画布上所有浮动图层与标注**烙进底图**（相当于保存，但不生成文件），此后画面上没有可再拖动的东西；**不影响撤销 / 重做** —— 定版本身也是一步操作，⌘Z 能整套还原。

**5、同色覆盖（抹除局部元素）：先设置或吸取颜色（全局吸管，动态显示颜色值），再使用实心矩形去遮盖目标区域。**

**6、支持 OCR 提取内容，导出 Markdown、Word、Excel：**

- （1）绝大部分情况下，只能解析出文字 + 表格；
- （2）部分图文混排的图片，可以解析出文字 + 图片（抠图）；
- （3）**识别范围按当前选中状态自动判定**：有浮动图层被激活选中 → 只认那一块；框了选区 → 只认框内；两样都没有 → 整张图；
- （4）结果窗默认是**「查看模式」**：把 Markdown 排版成正常格式（标题 / 列表 / 真表格 / 代码块 / 图片直接显示），可一键切到**「源码模式」**查看或编辑原始 Markdown（导出用的就是源码）；
- （5）识别结果**自动写入剪贴板**，写的是查看模式的内容 —— 带格式的富文本（粘到 Word / WPS / 微信直接带样式）+ 渲染后的纯文本（表格是 Tab 分隔，粘进 Excel 能直接分列）；
- （6）后台对接免费的 MinerU 接口，Token 申请地址：<https://mineru.net/apiManage/token>；
- （7）配置文件路径：`~/.SnipMagic.ini`（主题、快捷键、马赛克密度、线条粗细、刷子粗细、超时时间、Token、火山 API Key 都存在这里）。「超时时间」是轻量解析的等待秒数，超时后自动改用精准解析（vlm）；**填 0 表示跳过轻量解析、直接使用精准解析**。

**7、支持常规编辑**：文字、画笔、箭头、直线、边框、序号、撤销、重做等。

**8、支持自动更新**：启动时静默检查云端新版本，发现后弹窗询问，同意才下载安装；按本机芯片（Apple 芯片 / Intel）自动匹配安装包。设置界面亦可手动检查。

## 功能特性

### 截图

| 模式 | 快捷键（默认） | 说明 |
| --- | --- | --- |
| 区域截图 | `⌘ ⇧ R` | 框选任意区域，自动排除本应用窗口；**不包含鼠标箭头 / 鼠标手势** |
| 长截图 | `⌘ ⇧ E` | 框选区域后滚动页面（网页/长文档），自动拼接为一张长图；同样不含鼠标箭头 |

**长截图拼接算法**：基于行签名（16 段）+ dy 偏移全搜索 + 候选像素校验 + 接缝精炼（SAD 相关性），支持吸顶/吸底检测、文档坐标去重与断档分隔，滚动重叠区域拼接自然无重影。

### 多页签编辑器

每次截图自动生成一个页签（P1、P2……），类似 Excel 底部的 Sheet 页签，可切换、可拖拽排序、右键关闭。

- **标注工具**：框选、矩形、椭圆、箭头、直线、自由画笔、文字、马赛克、序号、擦除刷、查看
- **无损编辑**：所有标注均可选中后移动、缩放、改样式，随时撤销/重做（`⌘Z` / `⌘⇧Z`）
- **文字标注**：字号、加粗、颜色可调，可选透明背景
- **马赛克**：密度可调（设置中 2–64 像素/格）

#### 侧栏工具怎么点

- **当前工具高亮**：选中的按钮铺主题蓝底、图标转白，一眼就知道接下来画什么；启动时默认停在「框选」。
- **单击 = 用一次就走**：箭头 / 直线 / 画笔 / 各种矩形椭圆这类"画一笔"的工具，落完一个图形就自动退回「框选」，
  不需要画完再手动点回去（新画的图形保持选中，可以直接拖动 / 缩放）。
- **双击 = 锁定，连着画**：双击这些工具，按钮右下角会出现一个**小锁**，之后可以连续画多个，不再自动退出
  —— 交互类似 Office 里"锁定的格式刷"。**再单击该按钮即可解除锁定**并回到「框选」。
- **持久模式**：框选、查看、擦除刷不会被自动退出（它们本身就是"一直待着"的工具）。
- **「查看」= 定版**：点「查看」时会先把画布上的浮动图层与标注**烙进画面**（画布上不再有能拖动的东西），
  只保留滚动 / 缩放；这一步同样可 `⌘Z` 退回。

### 左右对比

把一个页签拖到右侧（或右键菜单 → 与当前页签对比），两张图并排显示：

- **同步滚动**：默认开启，两图横向 + 纵向联动滚动；可用工具栏开关关闭，独立滚动
- **独立缩放**：两栏各自支持 `⌘ + 滚轮` 缩放
- 「退出对比」按钮在右上角，一键恢复单图

### 缩放

- `⌘ + 鼠标滚轮`：放大/缩小（10%–800%，接近 100% 自动吸附），方向为**上滚缩小、下滚放大**
- 触控板双指捏合同样可缩放
- 任意缩放倍数下，标注的绘制、框选、拖动依然精确

### 复制 / 粘贴

`⌘C` 按以下优先级智能识别你要复制的内容：

1. 橡皮筋选区（选择工具框选的区域）
2. 浮动图层（框选后拖动起来的区域）
3. 选中图形的包围盒区域（用矩形等工具画的框，自动排除边框线）
4. 整张图片

`⌘V` 粘贴为可拖动的浮动图层，状态栏会提示复制/粘贴了什么。

### 保存

- `⌘S`：保存当前页签，文件类型可选，**默认 PNG（无损）**，JPEG 可选（文件小）
- **全部保存**：工具栏按钮或页签右键菜单，一次把所有页签导出到指定文件夹，文件名自动去重

### 颜色

- 侧栏底部颜色按钮：无边框色块，实时显示当前画笔颜色
- 自定义颜色面板：**经典彩色圆盘**（角度 = 色相，半径 = 饱和度）+ 明度滑杆 + R/G/B/透明度 + HEX 输入
- **全屏吸管**：冻结屏幕 + 10 倍放大镜 + HEX 实时显示，可取屏幕任意位置的颜色（当前图片、桌面壁纸、其他软件都行），左键取色、`Esc` 取消
- 文字编辑面板使用同一套颜色选择逻辑

### 提取内容（OCR 文字 / 表格 / 图片）

工具栏「📋 提取内容」按钮：识别图片中的文字、表格与图片，结果以 Markdown 形式展示并自动复制到剪贴板，可直接编辑后导出。

**识别范围按当前选中状态自动判定**（优先级从上到下，命中一条就停）：

| 当前状态 | 识别范围 |
| --- | --- |
| 有浮动图层被激活选中（用「框选」点中它） | **只识别那一块** —— 走图层自身的像素，不含它下面那一层 |
| 用「框选」拖出了一个框 | 只识别框内的画面 |
| 两样都没有 | 整张图（底图 + 所有浮动图层合成） |

**双引擎自动切换**（基于 MinerU 云服务，**需要联网**）：

| 引擎 | 说明 | 触发条件 |
| --- | --- | --- |
| 轻量解析 | 免登录、免 Token，速度快 | 默认优先尝试 |
| 精准解析（vlm） | 识别更准、可提取图片 | 轻量超时 / 失败 / 结果含图片占位时自动降级 |

结果窗口底部会标注本次使用的引擎（轻量 = 灰色 / 精准 = 蓝色）。「设置」里的**超时时间**是轻量解析的等待秒数，**填 0 表示跳过轻量解析、直接使用精准解析**（需先填好 Token）。

**结果窗有「查看模式 / 源码模式」两档**（默认查看模式，右上角切换）：

- **查看模式**：把 Markdown 排版成正常格式 —— 标题、列表、引用、代码块、**真表格（带框线）**，识别出的图片直接显示在正文里；
- **源码模式**：显示并可编辑原始 Markdown；**导出 Markdown / Word / Excel 用的都是这一份源码**。

**自动写入剪贴板的内容 = 查看模式的那一份**：带格式的富文本（粘到 Word / WPS / 微信直接带样式）+ 渲染后的纯文本（表格是 `Tab` 分隔，粘进 Excel 能直接分列），而不是一堆 `**` 和 `|`。

**导出（三种格式，均支持图片）**：

- **导出 Markdown**：有图片时生成一个**文件夹**（Markdown 文件 + `images/` 图片目录，引用完整可读）；无图片时导出单个 `.md` 文件
- **导出 Word**：图片内嵌到正文（行内图片，超宽自动等比缩放到 A4 版心）
- **导出 Excel**：图片内嵌到工作表（浮动锚定到对应行）

> 精准模式（vlm）才会返回可导出的图片；轻量模式对含图页面只返回占位，工具会自动改走精准模式获取真实图片。精准模式需在「设置」中填入 MinerU Token（在 [mineru.net](https://mineru.net) 的「API 管理」页面创建）。

> ⚠️ **兼容性提示（Mac 版 WPS）**：若导出的 Markdown 文件夹存放在自定义目录（如项目文件夹）下，用 **Mac 版 WPS** 打开时正文正常但图片无法加载——这是 WPS 沙盒限制所致，并非导出文件的问题。把整个导出文件夹移动到「下载 / 桌面 / 文稿」目录即可正常显示，详见[常见问题](#用-mac-版-wps-打开导出的-markdown图片显示不出来)。

`测试文件/` 目录下有实际导出效果样张（含图文混排页面的 Word / Excel / Markdown 文件夹导出结果），可直接打开查看。

### 魔法消除（AI 擦除 + 背景重建）

工具栏「🪄 魔法消除」按钮：把画面里不想要的东西抹掉，并用 AI 重建被遮住的背景。

**两种指定范围的方式**（任选，同时存在时刷子优先）：

| 方式 | 操作 | 适合 |
| --- | --- | --- |
| 擦除刷 | 侧栏选中「擦除刷」，在图上按住拖动刷出要抹掉的区域 | 任意形状、零散目标 |
| 矩形框选 | 用「选择」工具拖一个框 | 规整的一块区域 |

- **刷子粗细**：设置里可改（4–240 px，默认 26），也可在刷子激活时按 `[` / `]` 临时调整；刷错了右键清空重刷
- **每一笔都可撤销**：刷完直接 `⌘Z`，逐笔回退
- 点按钮后云端处理，一般 3–6 秒出结果；进度浮层会实时显示阶段（上传 → 重建 → 取回）
- 使用遮罩时要盖满目标 —— 没盖到的部分会被当作背景保留下来

**需要配置**：本功能调用火山引擎 AI MediaKit 的图像擦除修复接口，需在「设置」→「火山 API Key」填入 API Key（在 [AI MediaKit 控制台](https://console.volcengine.com/imp/ai-mediakit/settings) 创建）。留空时点击该按钮会提示去配置。

> 擦除时图片会临时上传到火山引擎，由云端模型处理后再取回；服务端上传文件 30 天后自动清理。
> 计费约 **0.0014 元/次**（1.38 元/千次，按成功次数计费，失败不计费）。

### 提取矢量图（AI 抠图 → 透明底图层）

工具栏「提取矢量图」按钮（小印章图标）：把画面里的主体从背景中抠出来，落成一个**透明底图层**，可以直接拖走、缩放，或 ⌘C 复制到微信 / Keynote / Pages / Word —— 带的是真 alpha，不是白底方块。

**用法**

1. 用「框选」工具把主体**连同一圈背景**框进来（留点边，模型更好认主体边缘）；也可以先用「框选」点中一个浮动图层，直接抠那个图层；
2. 点工具栏的「提取矢量图」；
3. 3–5 秒后画布上多出一个透明底图层，自动选中并**与原位置错开 8 像素**摆放（默认往左上；主体贴着画布左 / 上边缘时自动改往右下，图层比画布还大时原地摆放），一眼就能看出哪块是新抠出来的，接着拖动 / 缩放 / `⌘C` 即可。

**说明**

- 送出去的是**"所见"的合成图局部**（底图 + 所有浮动图层），所以浮动图层里的内容一样能抠；
- 结果会**自动裁掉四周透明边**，且位置自动对齐到原图对应位置（不是整块贴上去）；
- 云端依次按 **通用 → 人像 → 商品** 三种场景尝试：只有"整张图都没认出主体"才换下一个场景，接口报错不重试（避免重复扣费），多数情况第一次就命中；
- 处理期间会显示进度浮层（上传 → 抠图 → 取回），**可点「取消」**中止；取消或失败都不改动图片；
- 落图层只需 `⌘Z` 一步撤销；
- 需要「设置」→「火山 API Key」（与「魔法消除」共用同一把）。留空时点击按钮会提示去配置；
- **注意**：选区太贴主体边缘、或主体本身就铺满选区时可能认不出主体，此时会提示重框；主体连同一圈背景一起框最稳。

### 自动更新（默认开启）

启动约 3 秒后静默检查 [Gitee Release](https://gitee.com/mrpu2020/SnipMagic_Mac/releases) 是否有新版本；也可以点「设置」→「版本更新」→「检查更新」手动触发。

- **只提示，不偷偷装**：发现新版本只弹窗，点「立即更新」才开始下载；点「稍后」本次不再打扰
- **自动匹配芯片**：按本机真实硬件挑安装包（`截图大师SnipMagic-vX.Y.Z.dmg` = Apple 芯片，`截图大师SnipMagic-vX.Y.Z-x86_64.dmg` = Intel）
- **替换有兜底**：先把旧版改名为 `.update-backup` 再覆盖，失败自动回滚；目录不可写时会打开 dmg 让用户手动拖，最差情况也不会把应用弄丢
- **不内置任何密钥**：读取 Release 走 Gitee 公开接口，无需令牌
- 安装包缓存在 `~/Library/Caches/截图大师SnipMagic/updates/`

> 因为软件使用**固定自签证书**签名（详见「从源码构建」），签名要求只与证书指纹绑定，所以更新替换后「屏幕录制」等系统授权仍然有效，不需要重新授权。
>
> ⚠️ **例外：v3.0.x → v3.1.0 这一次改名升级**。改名同时把 Bundle ID 从 `com.mimo.screenshottool` 换成了 `com.mimo.snipmagic`，签名要求里的标识符变了，系统会把它当成一个新应用 —— 所以升级到 v3.1.0 后需要**重新授权一次**「屏幕录制」，之后再更新就不会再要了。旧版本（≤ v3.0.1）的 App 仍在 `/Applications` 里的话建议一并删掉。

- **自定义快捷键**：设置中可录制修改（至少含一个修饰键），支持恢复默认
- **主题**：设置中可选「暗色 / 亮色 / 跟随系统」（默认跟随系统），调整整体背景色；保存在配置文件 `theme=` 键，老版本配置无此项时按「跟随系统」处理
- **可调参数**：马赛克密度、线条粗细、擦除刷粗细、提取内容超时时间（轻量解析等待秒数，默认 10s，超时自动降级精准模式）、MinerU Token（精准模式所需）、火山 API Key（魔法消除 / 提取矢量图所需）
- 设置页显示当前版本号与打包时间，并提供「检查更新」入口

### 配置文件 `~/.SnipMagic.ini`

首次启动自动创建，设置界面保存时全量写回：

| 键 | 说明 | 缺省 |
| --- | --- | --- |
| `capture_hotkey` | 区域截图快捷键（如 `Command+Shift+R`） | `Command+Shift+R` |
| `long_hotkey` | 长截图快捷键 | `Command+Shift+E` |
| `theme` | 主题：`dark` / `light` / `system` | `system`（跟随系统） |
| `mosaic` | 马赛克密度（2–64 像素/格） | `10` |
| `line_width` | 线条粗细（1–40 像素） | `4` |
| `erase_brush` | 擦除刷直径（4–240 像素，魔法消除用） | `26` |
| `agent_timeout` | 轻量解析等待秒数（5–600），超时降级精准解析 | `10` |
| `token` | MinerU Token（精准解析 vlm 用） | 空 |
| `volc_key` | 火山引擎 AI MediaKit API Key（魔法消除 / 提取矢量图用） | 空 |

> **改名迁移（v3.0.1 → v3.1.0）**：新版本首次启动时，若发现旧的 `~/.截图工具` 而 `~/.SnipMagic.ini` 还不存在，会**自动把内容整体搬过来**（你填过的 MinerU Token、火山 API Key 等全部保留），旧文件改名为 `~/.截图工具.bak` 留档。迁移只做一次。
>
> **老配置兼容**：从旧版本升级上来的配置文件里没有 `theme` 项，此时一律按「跟随系统」处理 —— 打开设置会显示「跟随系统」，点确定保存后才会把 `theme=` 写进文件。

## 使用指南

### 基本流程

1. 点击菜单栏图标、窗口内「开始截图」按钮，或按 `⌘⇧R`；
2. 框选区域 → 松开即完成截图，自动进入编辑器；
3. 用左侧工具栏标注（矩形/椭圆/箭头/直线/画笔/文字/马赛克/序号）：单击工具画一笔就自动回到「框选」，要连着画多个就**双击**该工具锁定它（右下角出现小锁）；
4. `⌘C` 复制、`⌘S` 保存，或继续截下一张（多页签管理）。

### 长截图

1. 按 `⌘⇧E`（或工具栏「长截图」按钮）；
2. 框选要拼接的区域（如浏览器内容区），出现控制面板；
3. 点击「开始」后在原窗口滚动页面，工具自动采集并拼接；
4. 滚到底后「完成」，得到一张完整长图。

### 左右对比

- 底部页签**按住拖到右侧**松手，或**右键 → 与当前页签对比**；
- 「同步滚动」开关默认开启，两图一起滚动；关闭则各自独立；
- 点击右上角「✕ 退出对比」恢复单图。

## 常见问题（FAQ）

### 用 Mac 版 WPS 打开导出的 Markdown，图片显示不出来？

**原因**：不是导出文件的问题。导出的 Markdown 使用标准相对路径引用 `images/` 目录中的图片，用 Typora、VS Code、Obsidian 或 Windows 上的 WPS 打开均正常。

问题出在 **Mac 版 WPS 的沙盒限制**：WPS for Mac 的文件读写白名单仅包含「桌面、文稿（文档）、下载」等少数目录。从其他任意目录（例如自定义项目文件夹）打开 `.md` 文件时，macOS 只授权 WPS 访问这个文件本身，同级的 `images/` 目录会被沙盒拒绝，因此正文正常、图片加载失败。

**解决办法**（任选其一）：

1. 把整个导出文件夹（`.md` 文件 + `images/` 目录）移动到**「下载」「桌面」或「文稿」**目录下，再用 WPS 打开；
2. 改用 Typora、VS Code、Obsidian 等编辑器打开（它们没有此限制）。

## 从源码构建

```bash
git clone https://gitee.com/mrpu2020/SnipMagic_Mac.git
cd SnipMagic_Mac

# 首次构建前：创建固定的代码签名证书（只需执行一次，详见下方「签名说明」）
./create_signing_cert.sh

# 编译运行（Swift Package Manager）
swift build --disable-sandbox
swift run ScreenshotTool

# 打包发布（同时产出 arm64 + x86_64 两份 dmg，自动签名 + 验证架构）
./build_app.sh

# 也可以单独打某一种架构：
# ./build_app.sh --native        # 只打 arm64 dmg（Apple Silicon）
# ./build_app.sh --x86_64        # 只打 x86_64 dmg（Intel Mac）
# ./build_app.sh --universal     # 打通用二进制 dmg（一包通吃）
# ./build_app.sh --app-only      # 只打 .app，不打 dmg
```

> `--disable-sandbox` 是 SwiftPM 在受限环境下构建的必要参数。
>
> **签名说明**：`build_app.sh` 优先用固定自签证书 `ScreenshotTool Self-Signed` 签名（由 `./create_signing_cert.sh` 生成）。这不是为了绕过 Gatekeeper（自签证书仍会被拦，首次打开需右键 → 打开），而是为了**自动更新后系统授权不失效**：macOS 的屏幕录制等权限按「代码签名要求（designated requirement）」记录，ad-hoc 签名（`codesign --sign -`）的要求绑在 cdhash 上、每次构建都会变，于是更新一次就要重新授权一次；固定证书的要求是 `identifier X and certificate root = H<指纹>`，只绑证书不看内容。证书不存在时脚本会自动退回 ad-hoc 并给出提示。
>
> **多架构说明**：本机为 Apple Silicon 时，脚本用 `swift build --triple x86_64-apple-macosx14.0.0` 交叉编译 Intel 版本，无需 Intel 机器。Swift 6.4 的 swift build 不支持 `--arch`，必须用 `--triple`；triple 版本号要跟 `Package.swift` 的 `platforms: [.macOS(.v14)]` 对齐。
>
> **架构约定**：`dist/截图大师SnipMagic.app` 永远只放 **arm64（M 芯片）** 版本，本机双击即用；只有 dmg 才区分架构（`截图大师SnipMagic-v3.3.0.dmg` = arm64，`截图大师SnipMagic-v3.3.0-x86_64.dmg` = Intel）。非 arm64 的 dmg 在 `/tmp` 临时目录里组装 .app，打完即删，不会污染 `dist/`。
